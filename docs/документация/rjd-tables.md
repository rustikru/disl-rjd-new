# Таблицы `XX_RJD_%`

Документ описывает таблицы и представления с префиксом `XX_RJD_`, которые
упоминаются приложением или SQL-скриптами репозитория. Полная baseline-схема
Oracle не хранится в проекте, поэтому для объектов без DDL указано только
назначение, подтверждённое кодом.

## Учетные записи и доступ

| Объект | Назначение | Состояние DDL |
| --- | --- | --- |
| `XX_RJD_USERS` | Пользователи, логин, имя, email, пароль, активность, основная организация | Внешняя схема |
| `XX_RJD_ROLES` | Роли и системный признак | Внешняя схема |
| `XX_RJD_USER_ROLES` | Связь пользователей с ролями | Внешняя схема |
| `XX_RJD_ROLE_PAGES` | Назначение кодов страниц ролям | Внешняя схема |
| `XX_RJD_ACCESS_GROUPS` | Группы доступа | Внешняя схема |
| `XX_RJD_ACCESS_GROUP_ROLES` | Связь групп доступа с ролями | Внешняя схема |
| `XX_RJD_DISABLED_PAGES` | Глобально отключённые страницы | `db/2026-11-02-page-visibility.sql` |
| `XX_RJD_SESSIONS` | Активные и отозванные сессии | `db/old/20261029_sessions.sql` |
| `XX_RJD_PASSWORD_RESETS` | Одноразовые токены сброса пароля | `db/old/20261028_password_resets.sql` |
| `XX_RJD_AUDIT_LOG` | Журнал административных действий | `db/old/20261029_audit_log.sql` |

## Отчёты и колонки

| Объект | Назначение | Состояние DDL |
| --- | --- | --- |
| `XX_RJD_REPORTS` | Реестр отчётов для редактора конфигурации | Описан в `docs/доработки/report-config-db-editor.md`, baseline вне репозитория |
| `XX_RJD_REPORT_COLUMNS` | Колонки отчётов | То же |
| `XX_RJD_REPORT_FILTERS` | Фильтры отчётов | То же |
| `XX_RJD_SOURCE_COLUMNS` | Исходные колонки справки | То же |
| `XX_RJD_REPORT_CONFIG_VERSIONS` | Версии конфигурации отчётов | То же |
| `XX_RJD_REPORT_CONFIG_AUDIT` | Журнал изменений конфигурации отчётов | То же |
| `XX_RJD_TABLE_LAYOUTS` | Пользовательская настройка таблицы для отчёта | `db/2026-11-04-table-layouts.sql` |
| `XX_RJD_TABLE_LAYOUT_COLUMNS` | Позиция, закрепление, видимость и индивидуальная ширина колонок в настройке | `db/2026-11-04-table-layouts.sql`, `db/2026-11-07-table-column-width.sql` |

Порядок колонок в `XX_RJD_TABLE_LAYOUT_COLUMNS` хранится по стабильному ключу,
а не по подписи. Исходный состав и стандартный порядок остаются в
`src/Reports/ReportConfig.php`. Отдельные layouts для разных вкладок пока не
выделяются: сохранение выполняется на уровне пользователя и отчёта.

## Предметные данные

| Объект | Назначение | Состояние DDL |
| --- | --- | --- |
| `XX_RJD_STATIONS` | Станции и координаты | Внешняя схема |
| `XX_RJD_CLAIM_NORMS` | Нормативы претензий | `db/old/20261025_claim_norms.sql` |
| `XX_RJD_KPI_TBL` | Определения KPI | Внешняя схема |
| `XX_RJD_KPI_ROW` | Строки KPI | Внешняя схема |
| `XX_RJD_KPI_TAB` | Вкладки/разделы KPI | Внешняя схема |
| `XX_RJD_KPI_TBL_V` | Представление выдачи KPI | Внешняя схема |

`XX_RJD_DISLOCATION_NEW_PKG` — пакет, а не таблица. Основные таблицы
дислокации имеют префикс `XX_DISL_`/`XX_DISLOCATION_` и в этот перечень не
входят.

## Проверка установленной схемы

Запросы для сверки объектов и колонок находятся в `db/rjd/`. Они только читают
словарь Oracle и не изменяют данные.
