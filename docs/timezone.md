# Часовой пояс приложения

Веб-приложение и CLI-задачи используют часовой пояс `Asia/Yekaterinburg` (UTC+05:00).

Настройка устанавливается в `src/Config.php`. Этот файл подключается как из
`public/index.php`, так и из `bin/run-mailings.php`, поэтому веб-запросы и
планировщик рассылок получают одинаковый часовой пояс PHP.

Часовой пояс операционной системы и Oracle этим изменением не меняется.
Значения Oracle типа `DATE`, хранящие местное время без часового пояса,
не следует дополнительно сдвигать при чтении или записи.
Числовые даты XLSX также хранят календарные компоненты без часового пояса.
`ImportController::parseExcelDate()` читает их через `Date::excelToDateTimeObject()` и сохраняет
полученные дату и время без перевода через Unix timestamp.

На странице «О системе» отображаются фактический часовой пояс PHP и его
текущий UTC-сдвиг. После установки следует проверить, что там указано
`Asia/Yekaterinburg (UTC+05:00)`.

Для CSV-экспорта дата в имени файла формируется по локальному календарю
браузера, без преобразования через UTC.
