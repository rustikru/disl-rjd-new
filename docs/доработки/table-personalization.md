# Настройка таблицы детализации

Настройка реализована для таблиц детализации, описанных в `ReportConfig`.

Пользователь может перетаскивать незакреплённые колонки за заголовок и менять
ширину любого столбца перетаскиванием его правой границы. Двойной щелчок по
границе возвращает автоматически рассчитанную ширину выбранного столбца. Кнопка
«Сбросить настройки таблицы» возвращает исходный порядок и автоматически
рассчитанные ширины. Фильтры по
колонкам работают в текущей виртуальной таблице и применяются к уже загруженным
строкам.

Порядок хранится по стабильным ключам колонок в таблицах:

- `XX_RJD_TABLE_LAYOUTS` — пользователь и код отчёта;
- `XX_RJD_TABLE_LAYOUT_COLUMNS` — ключ, позиция, закрепление и индивидуальная ширина колонки.

Новые колонки добавляются в конец, удалённые игнорируются. Закреплённые колонки
остаются недоступными для перемещения. Сервер проверяет каждый ключ по
`ReportConfig` перед сохранением. Ширина хранится в `COLUMN_WIDTH` по ключу
колонки, отдельно для пользователя и отчёта; допустимый диапазон — 70–800 px.
При сохранении порядка существующие ширины сохраняются. Новые колонки без
сохранённой ширины используют автоматический расчёт.

Ручной экспорт Excel использует текущий порядок таблицы. Для каждого отчёта в
настройках рассылки можно включить «Мой порядок колонок». По умолчанию используется
стандартный порядок из `ReportConfig`; при включённой опции рассылка применяет
сохранённый layout владельца рассылки.

API настройки:

- `GET /api/table-layout/{report}` — получить актуальный порядок;
- `POST /api/table-layout/{report}` — сохранить массив ключей `columns` либо объект `widths` вида `{"cargo_name": 240}`. Значение `null` сбрасывает индивидуальную ширину выбранного столбца;
- `POST /api/table-layout/{report}/reset` — удалить пользовательский порядок.

Все POST-запросы требуют CSRF. Миграция `db/2026-11-07-table-column-width.sql`
добавляет `COLUMN_WIDTH` в `XX_RJD_TABLE_LAYOUT_COLUMNS`; её необходимо применить
в Oracle до развёртывания PHP-кода. Настройка не расширяет доступ к данным и не
изменяет серверные фильтры организаций, ролей и областей данных.
