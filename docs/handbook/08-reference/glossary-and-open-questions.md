# Глоссарий и вопросы, требующие уточнения

## Глоссарий

| Термин | Простое объяснение |
|---|---|
| API | URL, по которому браузер получает или отправляет данные без полной перезагрузки страницы |
| Controller | PHP-класс, который принимает HTTP-запрос и формирует ответ |
| Service | Класс с повторно используемой логикой предметной области |
| Middleware | Промежуточная проверка запроса до вызова маршрута: сессия, вход, право и т. п. |
| Route | Связка HTTP-метода и URL с обработчиком |
| Bind-параметр | Значение SQL, переданное отдельно от текста запроса |
| KPI | Ключевой показатель, отображаемый в карточке |
| Детализация | Более подробные строки/группы, из которых складывается показатель или отчёт |
| ReportConfig | Реестр определения отчётов, фильтров, API и колонок |
| PageRegistry | Реестр страниц, URL, прав и пунктов меню |
| VPD | Oracle Virtual Private Database — политика, ограничивающая строки, видимые SQL-пользователю |
| OCI8 | PHP-расширение для подключения к Oracle |
| CSRF | Подделка запроса от имени пользователя; защита проверяет токен формы/запроса |

## Вопросы, которые нельзя закрыть только этим архивом

1. Каковы точные версии PHP, Slim и библиотек? Нет Composer manifest/lock.
2. Какие настройки реально заданы на TEST и PROD? Нет `rjd_config.php`.
3. Как настроен веб-сервер, document root и rewrite? Есть `public/.htaccess`, но нет конфигурации Apache/Nginx.
4. Где находятся `bin/downloads_mail_rjd.php` и другие CLI-скрипты? В архиве они отсутствуют, хотя один маршрут подключает такой файл.
5. Как именно планировщик вызывает рассылки и с какой частотой? Нет CLI-файла и cron/systemd.
6. Применены ли SQL-миграции из `db/` и `db/data_scopes/` на PROD?
7. Какие полные DDL у таблиц `XX_RJD_*`, `XX_DISLOCATION_RJD` и представлений?
8. Какие права выданы DB-пользователю приложения на пакеты, таблицы, представления и `DBMS_RLS`?
9. Какой часовой пояс задан в CLI PHP, PHP-FPM и Oracle-сессии?
10. Какие источники/процедуры наполняют `XX_DISLOCATION_RJD` и `XX_RJD_KPI_TBL_V`?
11. Какие разделы доступны для каждой реальной роли на PROD?
12. Какие интеграции (почта, LDAP, Kerberos, загрузка справок) включены в текущей среде?

## Не делать предположений

До получения подтверждений не следует утверждать, что конкретная миграция применена, планировщик работает, рассылка отправляет email, часовой пояс PROD совпадает с локальным или конкретная роль имеет доступ. Эти вопросы требуют проверки среды.
