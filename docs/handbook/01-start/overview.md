# Обзор проекта

## Для чего нужен проект

«Дислокация» — веб-приложение для просмотра и анализа сведений о железнодорожных вагонах. По коду видны разделы общей дислокации, подхода и отправления вагонов, погрузки, простоев, технического состояния, претензий, сырья, анализа за период, карты, карточки вагона, импорта справок, справочников и администрирования.

В проекте есть два основных пользовательских сценария:

1. **Просмотр данных:** браузер открывает страницу, JavaScript запрашивает JSON у API, PHP обращается к Oracle, после чего интерфейс показывает таблицы, KPI и детализации.
2. **Управление:** пользователь с нужными правами изменяет справочники, настройки, роли, рассылки и другие данные через WEB-формы и POST-маршруты.

## Технологии, подтверждённые исходниками

| Технология | Где используется |
|---|---|
| PHP 8-синтаксис | Серверная логика, контроллеры, сервисы и шаблоны |
| Slim | Создание приложения, группы и маршруты в `public/index.php`, `src/routes.php` |
| PSR-7 / PSR-15 | Объекты HTTP-запросов/ответов и middleware |
| Oracle | Основное хранилище данных и бизнес-расчётов |
| OCI8 | Драйвер Oracle; `src/Database/OracleDb.php` |
| JavaScript | `public/assets/js/app.js` и отдельные модули |
| jQuery | Локальная библиотека `public/assets/js/jquery/jquery-3.7.1.min.js` |
| Chart.js | Локальная библиотека Chart.js 4.5.0 |
| Leaflet | Карты и кластеры маркеров |
| CSS | Общие стили `app.css`, отдельные стили авторизации и карты вагона |

Точные версии PHP, Slim и Composer-пакетов в архиве установить нельзя: `composer.json`, `composer.lock` и `vendor/` не приложены.

## Основные подсистемы

- **Авторизация:** локальная учётная запись, LDAP и Kerberos; реализация в `src/Auth/`.
- **Сессии:** `SessionMiddleware`, `SessionRegistry`, CSRF-токен.
- **Доступ:** роли, права на страницы, глобальная видимость и области данных.
- **Отчёты:** реестр `ReportConfig`, API-методы `ApiController`, клиентская логика `app.js`.
- **KPI:** данные из Oracle-представления `XX_RJD_KPI_TBL_V` и процедур пакета `XX_RJD_DISLOCATION_NEW_PKG`.
- **Карточка вагона:** `WagonConfig`, `WagonMovement`, `templates/wagon.php`.
- **Экспорт:** Excel-экспорт и экспорт виртуальных/матричных таблиц.
- **Рассылки:** `MailingController`, `MailingService`, `MailingRun`, `OracleMail`.
- **Администрирование:** пользователи, роли, группы доступа, организации, настройки, видимость, обслуживание и аудит.

## Главный принцип устройства

Не начинайте разработку с создания нового класса или второго списка настроек. Сначала найдите существующий механизм:

- страница и права — `PageRegistry`;
- отчёт и его UI/API-конфигурация — `ReportConfig`;
- структура карточки вагона — `WagonConfig`;
- параметры приложения — `ConfigSchema`;
- доступ к Oracle — `DbInterface` и `OracleDb`.

Это требования самого проекта из `AGENTS.md` и комментариев в коде.
