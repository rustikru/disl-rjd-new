# Добавление страницы

Конфигурация страницы хранится в `PageRegistry`. Для стандартного отчёта не
создаётся отдельный шаблон: страница получает отчёт из `ReportConfig` и KPI из
`KpiTypeRegistry`, а общий layout подключается приложением.

## Стандартный отчёт

1. Добавить именованный метод `ReportConfig::<page>()` с endpoint-ами,
   фильтрами, колонками, группировками и экспортом.
2. Добавить именованный метод `KpiTypeRegistry::<page>Kpi()` и связать его с
   кодом страницы. Публичный метод `KpiTypeRegistry::<page>()` возвращает
   конфигурацию KPI страницы.
3. Добавить страницу и навигацию в `PageRegistry` или расширить существующую
   запись отчёта. HTML-ID и `container_key` задаются только в реестрах.
4. Проверить прямые маршруты, права, KPI, экспорт и узкий экран.

Страницы `approach`, `departure`, `loading` и `downtime` используют общий
`templates/partials/wagon-report.php`.

## Уникальный экран

Для особой разметки в запись страницы добавляется `custom_template` вида
`pages/<page>.php`. Такой шаблон подключается внутри общего shell приложения.
Карта остаётся отдельным маршрутом `/maps` и открывается с `target => '_blank'`.

После изменения запускаются `php -l`, `node --check`, `composer check:registry` и
`git diff --check`.
