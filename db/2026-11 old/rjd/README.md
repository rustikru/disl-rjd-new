# Скрипты схемы `XX_RJD_%`

В каталоге находятся безопасные диагностические скрипты для сверки схемы
Oracle с [описанием таблиц](../../docs/rjd-tables.md). Скрипты не создают и не
удаляют объекты.

Запускать под владельцем схемы:

```sql
@01_inventory.sql
@02_columns.sql
```

Миграции, создающие объекты, пока остаются в исходных каталогах `db/` и
`db/data_scopes/`, чтобы не менять порядок существующего развёртывания.
