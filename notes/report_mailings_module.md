# Модуль рассылок отчётов

## Состав

- `ReportCatalog` — единый список отчётов, фильтров и колонок.
- `MailingData` — хранение рассылок, расписание и очередь запусков.
- `ReportBuilder` — получение данных и создание XLSX.
- `MailingSender` — формирование и отправка писем из очереди.
- `bin/run_report_mailings.php` — запуск по cron.

XLSX для обычной выгрузки и для рассылки формируется одним классом
`ExcelExporter`. Поэтому структура листа, заголовки и группировки совпадают.

## Установка

1. Последовательно выполнить миграции `008`–`012` из `db/migrations/` в Oracle 11.
2. Добавить в `rjd_config.php`:

```php
'report_mail_enabled' => true,
'report_mail_test' => true,
'report_storage_dir' => __DIR__ . '/storage/reports',
```

3. Настроить запуск каждую минуту или каждые пять минут:

```cron
*/5 * * * * php /path/to/project/bin/run_report_mailings.php >> /path/to/project/tmp/log/report_mailings.log 2>&1
```

Если `report_mail_enabled = false`, скрипт только добавляет наступившие рассылки в очередь и не отправляет письма.

Если `report_mail_test = true`, письмо не отправляется через Oracle. Все вложения и
`message.json` со списком файлов сохраняются в `storage/reports/test/`. Кнопка запуска в списке
рассылок добавляет отчёт в очередь сразу, без ожидания времени расписания.

Одна рассылка может содержать до десяти отчётов. У каждого вложения отдельно
задаются вид отчёта, организация и фильтры. Получатели, тема письма и расписание
задаются один раз для всей рассылки.

## Добавление отчёта

Новый отчёт добавляется в `src/Reports/ReportCatalog.php` и в таблицу методов
`ReportBuilder::reportMethod()`. Универсальная форма строит фильтры автоматически.

Вызов пакета Oracle находится в методе `MailingSender::sendMail()`. Пока название
пакета и параметры не определены, вызов закомментирован и отправка завершается ошибкой.
